# Huawei AIRI 横屏测试包

适用测试设备：HUAWEI MatePad DBR-W10，HarmonyOS 4.2。这是 Android APK 测试包，不是 HarmonyOS NEXT 原生应用，尚需目标平板验收。

1. 将 APK 复制到平板，通过“文件管理”打开安装。
2. 如果提示禁止安装：设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 文件管理 → 允许安装应用。
3. 安装后点击桌面的 Huawei AIRI。应用请求横屏运行，左右两种横屏方向均可。
4. 平板连接能访问 AIRI API 的网络。无需 Node.js、NVM、Windows 启动脚本或电脑在线。

## 验收步骤

### test.2 新增的触控与图片操作

生成结果下方有“保存原图”和“分享”，点击图片可进入原图预览。预览支持双指缩放、放大后拖动、双击放大/复位，也可使用放大、缩小、复位和关闭按钮。系统返回键优先关闭原图预览。

在 Android 中，“保存原图”先准备图片，再打开系统保存窗口：选择文件夹/文件名并确认，完成后才显示已保存。取消选择不会保存文件，也不会显示失败。它保存到用户选择的文件位置，不自动写入相册。可使用系统文件管理打开该图片。

“分享”把原图文件交给系统分享面板，由用户自行选择接收应用；打开面板不代表已发送成功。图片准备期间不可重复点击，下载或写入失败可重试。支持 JPEG、PNG、WEBP，单张上限 50 MB。分享缓存最多保留五张，后续导出时清理一天前的缓存；系统也可回收缓存。

浏览器版本通过浏览器下载列表保存文件；系统分享能力可用时分享原图链接，能力不可用时提示先保存。网页端下载仍受图片服务器 CORS 限制，Android 使用原生下载。

仍需在目标平板验收系统保存窗口、文件名修改、取消、磁盘不足、分享给目标应用和重启后的行为。

### 真机检查

- 检查华为标志、红色按钮、星空背景、中文/英文切换。
- 文生图：打开模板、选中模板、生成并等待结果。
- 图生图：从文件/相册选择底图及 1–3 张参考图，输入提示词，生成并等待结果。
- 滚动左侧表单，底部生成按钮应始终可见。检查键盘弹出/收起后页面正常。
- 打开模板时按系统返回键应关闭模板；页面之间可返回；首页返回应退到桌面。
- 如失败，请提供系统/WebView 版本、报错截图、准确时间；不要发送认证 token。

网页和模板图片已打包在 APK 中，生成仍依赖后端。此内部包沿用已授权的构建时 token；更换 token 后需要重新构建。仅交付指定测试设备。
