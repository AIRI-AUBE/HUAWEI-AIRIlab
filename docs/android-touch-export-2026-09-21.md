# 触控、原图预览与导出 — test.2

本次按用户确认的方案补齐文生图/图生图结果的触控与下载交互，保留华为标志、原有红色和星空视觉。

## 产品行为

- 触控设备主要分类、参考标签、模板、生成、导航和语言按钮增加至至少 48 CSS px 高；分类改成两列。表单独立滚动，生成按钮保持在表单底部。
- 两种生成结果都提供“查看大图 / 保存原图 / 分享”。原图预览使用 output.url，列表可使用 thumbnail；导出绝不使用 thumbnail。
- 预览支持 1–4 倍双指缩放、放大后拖动、双击放大/复位，以及点击放大/缩小/复位。关闭按钮、Escape 和 Android 返回键可退出预览。
- Android 保存：原生 HTTPS 下载到有限缓存，验证图片和 50 MB 上限，打开系统“创建文件”窗口，写入成功后显示用户选择的文件名。取消不报错；写入失败尝试移除本次创建的不完整文件。
- Android 分享：将原图文件用限范围 FileProvider 临时授权交给系统分享面板；用户选择接收应用。提示只表明面板已打开，不声称已发送。
- 浏览器保存：下载原图字节并用实际图片格式命名，提示查看浏览器下载列表。浏览器分享：支持 Web Share 时分享原图 URL，不支持时提示先保存。
- 下载期间阻止重复点击，错误保留重试入口。只接受 HTTPS 原图；不向图片域名发送 AIRI token。原生端重定向仍检查 HTTPS/本地地址，最多五次；限制下载大小和读取时长。
- 缓存分享图片最多五张，后续导出清理一天前缓存。FileProvider 范围收紧到应用 Pictures 与 image-exports 缓存目录。无新增危险权限。
- 小于 1000 CSS px 的预览不再强制 600px 宽；640px 及以下改为纵向排列并可滚动查看。
